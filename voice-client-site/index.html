rewired-voice-client

Stream your local microphone to a remote Rewired agent — no browser needed.

Download

Pre-built binaries aren't ready yet. For now, build from source:

🐧 Linux → install.sh 🍎 macOS → install.sh 🪟 Windows (get Rust + build)

Linux / macOS — run in terminal:

curl -sSfL https://rewired-agent.vercel.app/install.sh | bash

Windows — run in PowerShell (as admin):

git clone https://github.com/Goncalo-Oliveira-Goncalves/rewired-agent
cd rewired-agent\voice-client
cargo build --release
mkdir $env:USERPROFILE\.local\bin -Force
copy target\release\rewired-voice-client.exe $env:USERPROFILE\.local\bin\

Requires Rust (rustup.rs). Builds from source and installs to ~/.local/bin/.

Once published, pre-built binaries will be on GitHub Releases.

Manual build

git clone https://github.com/Goncalo-Oliveira-Goncalves/rewired-agent
cd rewired-agent
cargo build --release -p rewired-voice-client
cp target/release/rewired-voice-client ~/.local/bin/

Install

# Download and make executable
mv ~/Downloads/rewired-voice-client* ~/.local/bin/rewired-voice-client
chmod +x ~/.local/bin/rewired-voice-client

# Or build from source
git clone https://github.com/anomalyco/rewired
cd rewired/voice-client
cargo build --release
cp target/release/rewired-voice-client ~/.local/bin/

Usage

In the Rewired TUI, type /voice. If no microphone is detected on the server, a relay starts and shows a connection address. On your local machine:

rewired-voice-client <server>:<port>

For example:

rewired-voice-client 192.168.1.50:43871
  1. Run the command on your local machine (the one with a microphone).
  2. Press Enter to start recording.
  3. Press Enter again to stop and transcribe.
  4. The transcribed text appears in the Rewired TUI and is automatically submitted.

How it works

The binary captures audio from your default microphone using cpal, encodes it as a WAV file, and sends it to the Rewired server via HTTP POST. The server transcribes it using the configured STT provider (Whisper, Groq, OpenAI, etc.) and delivers the text back into the TUI chat.

Requirements

Any modern Linux, macOS, or Windows system with a microphone. No runtime dependencies — the binary is statically linked.

Build from source

git clone https://github.com/anomalyco/rewired
cd rewired/voice-client
cargo build --release

# Optional: cross-compile for other targets
cargo install cross
cross build --release --target aarch64-apple-darwin
cross build --release --target x86_64-pc-windows-gnu
