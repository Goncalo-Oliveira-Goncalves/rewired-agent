How it works

Three steps to your own AI swarm. No lock-in, no hidden costs.

1

Install Rewired

One command on your server or local machine. The installer sets up everything — Python venv, dependencies, and config.

2

Configure

Run the setup wizard to add API keys, connect messaging platforms (Telegram, Discord, Slack), and enable voice.

3

Talk to your agents

Use the CLI, TUI, or any connected platform. Voice input works from your local machine via the Rewired Voice Client.

No problem at all

        
Rewired runs on any Linux server, macOS, Windows, or inside Docker. Here's a universal starting point:


        

          

            Quick start (Linux / macOS)
            
          

          
# Install Python 3.10+ and pip
# Then install Rewired:

git clone https://github.com/Goncalo-Oliveira-Goncalves/rewired-agent.git
cd rewired-agent
pip install -e .

# Run setup:
rewired setup

        


        

          Prefer Docker? We also have a docker-compose.yml for one-command deployment.

Features

    
Everything you need to run production AI agents.

  

  

    

      
🌍

      
Multi-platform

      
Telegram, Discord, Slack, WhatsApp, Signal, CLI, and more. Start on one, pick up on another.

    

    

      
🔊

      
Voice-enabled

      
Push-to-talk from any device. Remote voice client streams your mic to the server for transcription.

    

    

      
🧠

      
Persistent memory

      
Agents remember context across sessions. Auto-generated skills that grow the longer it runs.

    

    

      
📋

      
Scheduled jobs

      
Natural language cron for reports, backups, and briefings. Runs unattended through the gateway.

    

    

      
🔀

      
Swarm delegation

      
Spawn isolated sub-agents with their own context and tools. Parallel task execution.

    

    

      
🔒

      
Sandboxed execution

      
Five backends — local, Docker, SSH, Singularity, Modal — with container hardening.
